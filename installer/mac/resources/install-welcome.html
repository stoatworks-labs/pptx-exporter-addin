Advanced Exporter for PowerPoint

This adds Advanced Exporter to PowerPoint for Mac, for your user account. It exports the open deck to the formats PowerPoint offers, with the options left in, and to the ones it never got round to: pictures at any size, handouts and notes pages, video, an HTML5 presentation, LaTeX, Markdown and a few more.

Nothing is copied into Applications. The installer puts one small file in PowerPoint’s add-ins folder, which points PowerPoint at pptx-exporter-addin.stoatworks-labs.com. The add-in runs from there, so it keeps itself up to date. Your decks are never uploaded: every export is made on this Mac.

PowerPoint has to be closed while it installs. If it’s open, the installer will ask to quit it.

macOS may ask whether Installer can access data from other apps. The other app is PowerPoint, and its add-ins folder is where this goes, so choose Allow.
